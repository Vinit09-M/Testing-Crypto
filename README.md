# Organization cryptography inventory fixture

This synthetic repository models a financial services organization with several
application teams, shared infrastructure, and archived data. It is intended for
static analysis and contains no real organization data, credentials, or private keys.
The examples are isolated source fixtures. No services need to be run.

Scan this ZIP directly, or extract it and push this directory's contents to a
new repository. In CipherSetu, enter your repository URL, use its default branch,
and set the confidentiality lifetime to 10 years to reproduce the documented run.
For a private repository, grant the scanner read-only access to repository contents.

The inventory maps paths to owners and explains what each example represents.
The sample encrypted envelope is supplied for inspection only. Its temporary
private key was not included.
